# maialune.com

The website for Maia Lune: home, privacy policy and help pages. Plain HTML and CSS, hosted on GitHub Pages.

- `index.html`: home page. When the Google Play page is live, swap the "Coming soon" button for the Play link.
- `privacy.html`: privacy policy. Update the date at the top whenever it changes.
- `support.html`: help and contact.
- `style.css`: shared look for every page.
- `CNAME`: tells GitHub Pages to use maialune.com.
- `fonts/`: Fredoka and Nunito (SIL Open Font License, see the OFL files), stored here so the site makes no calls to font services.
